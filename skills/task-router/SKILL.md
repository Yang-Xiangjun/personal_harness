# Task router

Identify the requested artifact and one observable sign it works. Answer read-only questions directly. For delivery, read the route table in `.quality/WORKFLOW.md` at the installed project root. Honor an explicit mode. Otherwise choose fast for a bounded reversible edit with a direct check, standard for changed behavior, high for broad impact or difficult recovery. Record why in one sentence.

Run `new TASK --mode MODE --objective "..."` via the project harness. Resume an existing contract when continuing the same work. Open requirements-clarification next. If the user requested only a plan, stop at the reviewed plan. If the project has no harness installation, explain the setup step before offering verification claims.
